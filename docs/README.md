# Documentation Split

`docs/` contains the human-facing documentation for both repo tracks.

- `operations/` documents the adversarial patch workflow, Colab runs, and local
  orchestration.
- `notes/`, `research/`, and `papers/` belong to the literature and evidence
  track.

If a file explains how to run or evaluate the patch pipeline, it belongs under
`docs/operations/`. If it captures paper notes, synthesis, or source material,
it belongs in the literature-oriented sections.
