# Adversarial Patch Experiments

Everything in this directory is part of the patch pipeline.

- `ultralytics_patch.py` is the main training and evaluation runner.
- `colab_run.ipynb` is the GPU/Colab execution path.
- `live_demo.py`, `failure_grid.py`, `physical_benchmark.py`, and
  `defense_eval.py` are patch-focused evaluation and demo utilities.

Research-loop automation does not belong here. Literature tooling lives under
`research/scripts/`.
